# Python Messenger MVP (Telegram Clone)

Это MVP мессенджера на Python с использованием `aiohttp`, `python-socketio`, `PyQt6` и `cryptography`.

## Структура проекта

- `database.py`: Модели данных SQLAlchemy для сервера и клиента.
- `server.py`: Серверная часть на aiohttp + python-socketio.
- `client.py`: Клиентская часть на PyQt6.
- `requirements.txt`: Список зависимостей.

## Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск сервера

Сервер использует SQLite по умолчанию (`server.db`). Для использования PostgreSQL измените `DATABASE_URL` в `server.py`.

```bash
python server.py
```

Сервер запустится на `http://localhost:5000`.

### 3. Запуск клиента

Запустите клиент в отдельном терминале. Можно запустить несколько экземпляров для тестирования переписки.

```bash
python client.py
```

### 4. Использование

1.  **Регистрация**: Введите имя пользователя и пароль, нажмите "Register". При этом генерируется пара ключей RSA (приватный сохраняется локально в `username_private.pem`, публичный отправляется на сервер).
2.  **Вход**: Введите имя пользователя и пароль, нажмите "Login".
3.  **Добавление контакта**:
    -   Узнайте имя пользователя собеседника (он должен быть зарегистрирован).
    -   Нажмите "Add Contact".
    -   Введите имя пользователя собеседника.
    -   Если пользователь найден, его публичный ключ будет сохранен локально, и он появится в списке контактов.
4.  **Чат**:
    -   Выберите контакт из списка.
    -   Введите сообщение и нажмите "Send".
    -   Сообщения шифруются публичным ключом получателя и расшифровываются приватным ключом получателя.

## Замечания

-   Это MVP версия. В ней упрощена обработка ошибок и безопасность хранения ключей.
-   База данных сервера по умолчанию SQLite для простоты запуска. Для продакшена рекомендуется PostgreSQL.
-   Сообщения хранятся на сервере в зашифрованном виде (но метаданные, кто кому писал, доступны серверу).
-   Клиент хранит историю сообщений и контакты в локальной базе данных SQLite (`client.db`).
